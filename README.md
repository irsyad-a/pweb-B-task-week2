# Irsyad Akbar | Portofolio

Website portofolio sederhana milik **Irsyad Akbar**, mahasiswa Teknik Informatika ITS, yang dibuat untuk memenuhi tugas mata kuliah **Pemrograman Web (B)**.

Website ini bukan portofolio profesional utama, melainkan sebagai project pembelajaran yang berfokus pada penerapan materi dasar **HTML** dan **CSS** saja. Isi website ini menampilkan profil, biografi, pengalaman, pendidikan, kemampuan, portofolio proyek, serta informasi kontak sebagai latihan penyusunan halaman web personal.

---

##  Tentang Website

Website ini merupakan halaman portofolio statis berbasis **HTML5** dan **CSS3**. Project ini dikerjakan sebagai tugas mata kuliah **Pemrograman Web (B) (EF234301)** yang diajarkan oleh **Fajar Baskoro, S.Kom., M.T.** Karena materi perkuliahan saat project ini dibuat baru mencakup HTML dan CSS, website ini belum menggunakan JavaScript, framework, backend, atau database.

Seluruh konten disusun dalam beberapa section utama agar pengunjung dapat mengenal profil, pengalaman, skill, dan proyek yang pernah dikerjakan dengan mudah dalam bentuk website personal sederhana.

Website ini memuat informasi seperti:

- Profil singkat
- Biografi
- Identitas dan kontak
- Pengalaman organisasi
- Riwayat pendidikan
- Kemampuan atau skill
- Daftar proyek portofolio
- Formulir kontak
- Link media sosial
- Tombol download CV

---

##  Fitur Utama

- **Navigasi Samping**  
  Memudahkan pengguna untuk berpindah ke section Depan, Biografi, Portofolio, dan Kontak.

- **Hero Section**  
  Menampilkan foto profil, peran sebagai Website Developer, serta informasi pribadi untuk tujuan karier.

- **Biografi**  
  Berisi deskripsi singkat mengenai latar belakang, pengalaman, dan ketertarikan di bidang teknologi serta desain.

- **Informasi Personal**  
  Menampilkan nama, tanggal lahir, usia, alamat, nomor telepon, Instagram, dan email.

- **Download CV**  
  Pengunjung dapat mengunduh CV melalui tombol yang tersedia.

- **Pengalaman**  
  Menampilkan pengalaman di Lembaga Minat Bakat ITS dan Jamaah Masjid Manarul Ilmi ITS.

- **Pendidikan**  
  Menampilkan riwayat pendidikan di Institut Teknologi Sepuluh Nopember dan MAN IC Bangka Tengah.

- **Kemampuan**  
  Menampilkan skill seperti Figma, HTML5 & CSS3, Adobe Photoshop, dan Adobe Illustrator.

- **Portofolio Proyek**  
  Menampilkan beberapa proyek seperti Website LMB ITS, Web Landing Page IBL, dan Web Form MBMT LMB ITS.

- **Kontak**  
  Menyediakan formulir kontak serta informasi alamat, telepon, dan email.
